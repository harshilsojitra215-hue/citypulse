## How to read the dates

- published_at: the source's own date (for page changes: the time we detected the change)
- modified_at: source says it changed, when known (OParl papers)
- discovered_at: first time our collector saw it, never changes
- last_seen_at (retrieved_at): last run that saw it again
- ingested_at: set by the pipeline when it loads the record, not by the collector

Relevance: radar_match (strong, weak, none) is the radar gate: strong = a project phrase, or a cable word and a place word in the same snippet fragment, at most 100 characters apart; weak = only one of them, or both far apart; none = neither or a negative word. All items stay stored. title_hit = the headline or text names the project (specific phrase, or keyword plus place word). Manual judgments (R relevant, U unclear, N not) exist only for items judged earlier by hand (data/relevance_judgments.json); new items are listed as not judged. Pipeline stage 2 and the labels decide relevance.
