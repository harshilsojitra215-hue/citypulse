## How to read the dates

- published_at: the source's own date (for page changes: the time we detected the change)
- modified_at: source says it changed, when known (OParl papers)
- discovered_at: first time our collector saw it, never changes
- last_seen_at (retrieved_at): last run that saw it again
- ingested_at: set by the pipeline when it loads the record, not by the collector

Relevance: title_hit = the headline or text names the project (specific phrase, or keyword plus place word). Manual judgments (R relevant, U unclear, N not) exist only for items judged earlier by hand (data/relevance_judgments.json); new items are listed as not judged. Pipeline stage 2 and the labels decide relevance.
